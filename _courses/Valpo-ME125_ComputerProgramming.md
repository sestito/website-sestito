## Student Learning Objectives
Students who complete ME 125 should be able to: 
1. Apply mathematics including statistics to the analysis of engineering problems. 
2. Develop and document computer programs so that others can understand and use them to solve engineering problems. 
3. Create and use Python script files. 
4. Create and use Python functions. 
5. Install and use Python Packages. 
6. Create a graph in accordance with the rules for engineering graphs using linear, log-log, or semi-log axes. 
7. Develop computer programs from a logical flow chart that involves looping and branching. 
8. Generate statistical properties
