## Undergraduate Projects
{: class="section-heading"}

If you are an undergraduate at Valpo in engineering interested in research, there are projects in some of the following areas!

* Optimization using Machine Learning: Learn how to apply machine learning methods to develop complex optimization algorithms for engineering design!
* Molecular Dynamics: Explore materials science at an atomic level!
* Finite Element Analysis: Learn how to programatically perform automated finite element analysis!
